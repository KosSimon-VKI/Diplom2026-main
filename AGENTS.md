# Правила для Codex

- Все ответы пользователю всегда давай на русском языке.
- Все текстовые файлы проекта сохраняй в корректной кодировке UTF-8. Не добавляй и не оставляй в исходниках битую кириллицу/mojibake, то есть русские надписи, превратившиеся в наборы символов из-за неверной кодировки.
- Если при чтении, редактировании или генерации текста видишь такие символы, обязательно восстанови нормальную русскую надпись перед завершением задачи.
- Перед финальным ответом после любых правок в текстовых файлах проверяй проект на типичные признаки битой кодировки:

```powershell
$sourceExts = @('.cs','.xaml','.cshtml','.js','.css','.json','.sql','.xml','.config','.csproj','.sln','.props','.targets','.txt','.md','.gitignore')
$badCodes = @(0x040F,0x201A,0x2026,0x2039,0x040A,0x040C,0x0452,0x0453,0x0459,0x045A,0x045C,0x045F,0x040E,0x040B,0x045B,0x201E,0x2020,0x2021,0x20AC,0x2030)
$badChars = $badCodes | ForEach-Object { [char]$_ }
Get-ChildItem -Recurse -File |
  Where-Object { $sourceExts -contains $_.Extension -and $_.FullName -notmatch '\\(bin|obj|\.git|\.vs|artifacts)\\' } |
  ForEach-Object {
    $file = $_
    try {
      $lines = [System.IO.File]::ReadAllLines($file.FullName)
      for ($lineIndex = 0; $lineIndex -lt $lines.Length; $lineIndex++) {
        foreach ($badChar in $badChars) {
          if ($lines[$lineIndex].IndexOf($badChar) -ge 0) {
            '{0}:{1}: {2}' -f $file.FullName, ($lineIndex + 1), $lines[$lineIndex].Trim()
            break
          }
        }
      }
    } catch { }
  }
```

- Если проверка нашла совпадения, не заверши задачу, пока не убедишься, что это не mojibake. Нормальная русская кириллица должна оставаться без изменений.

## Правило для новых CRUD-окон GardenNookWpf

- Новое CRUD-окно должно быть модальным WPF-окном в стиле существующих окон проекта: без стандартной рамки Windows, с общей модальной оболочкой, шапкой, рабочей областью и нижней панелью действий.
- Окно создавай в папке соответствующего раздела: `Views/MainPanel/<Раздел>/<Entity>EditWindow.xaml`, а для удаления: `ConfirmDelete<Entity>Window.xaml`.
- Для оформления обязательно используй общие ресурсы из `App.xaml`: `ModalShellBorder`, `ModalHeader`, `ModalHeaderTitle`, `ModalCloseButton`, `ModalCardBorder`, `ModalPrimaryButton`, `ModalSecondaryButton`, цвета `ModalColor...`.
- Базовая структура XAML: `WindowStartupLocation="CenterOwner"`, `ResizeMode="NoResize"`, `WindowStyle="None"`, для обычных модальных окон `AllowsTransparency="True"` и `Background="Transparent"`, корневой `Border Style="{StaticResource ModalShellBorder}"`, внутри `Grid` из трех строк: шапка, контент, нижние кнопки.
- Шапку делай через `Border Style="{StaticResource ModalHeader}"`, заголовок через `ModalHeaderTitle`, кнопку закрытия через `ModalCloseButton` с нормальным символом `×` или `✕`.
- Заголовок окна должен отражать режим: `Добавить ...` или `Создать ...` для добавления, `Редактировать ...` или `Изменить ...` для редактирования, `Удаление ...` для удаления.
- Для добавления и редактирования используй одно окно, если форма одинаковая. В конструктор передавай существующую модель nullable-параметром, например `EntityDto? existingEntity = null`; если модель `null`, окно работает как добавление, иначе как редактирование.
- CRUD-окно не должно само вызывать API. Оно только показывает поля, валидирует ввод, собирает `Request` или результат и выставляет `DialogResult = true`. API-запросы, перезагрузка списков и статус операции должны оставаться во View или Controller раздела.
- После успешного `ShowDialog() == true` вызывающая View отправляет `POST`, `PUT` или `DELETE`, при успехе перезагружает список и показывает статус вроде `Изменения сохранены.` или `Позиция удалена.`, а при ошибке показывает сообщение API через `StatusText` или `SetStatus`.
- Для ошибок внутри формы используй `TextBlock x:Name="ValidationText"` с красным цветом `#FFB33131`, `FontWeight="SemiBold"` и `Visibility="Collapsed"` по умолчанию. В code-behind добавляй методы `ShowValidation(...)` и `HideValidation()`.
- Валидацию выполняй до `DialogResult = true`: обязательные поля проверяй на пустоту, строки обрезай через `Trim()`, названия нормализуй с удалением лишних пробелов, числа парсь с учетом `CultureInfo.CurrentCulture` и при необходимости поддерживай точку/запятую, отрицательные значения запрещай там, где они невозможны, выбор из списков проверяй через `SelectedItem` или `SelectedValue`.
- Закрытие окна делай единообразно: `Cancel_Click` и `HeaderClose_Click` выставляют `DialogResult = false` и закрывают окно.
- Шапку окна делай перетаскиваемой через `Header_MouseLeftButtonDown` и `DragMove()`, если нажата левая кнопка мыши.
- Для больших форм используй `WindowState="Maximized"` и внутренний `ScrollViewer` или `TabControl`, как в техкартах, меню и актах списания. Для коротких форм используй фиксированный размер примерно `680x360`, `760x430` или `860x720`.
- Для сложных сущностей разделяй форму: простые поля помещай в карточки `ModalCardBorder`, длинные формы дели на вкладки, списки выбора делай через `ListBox` с поиском, табличные составы через `DataGrid`, вложенные строки добавляй и удаляй внутри окна, но сохраняй только одним финальным действием.
- Кнопки действий размещай в нижней панели справа: основная кнопка `Добавить`, `Сохранить` или `Создать акт`, рядом вторичная кнопка `Отмена`.
- Удаление всегда делай через отдельное `ConfirmDelete...Window`, а не через обычный `MessageBox`, если это CRUD-сущность. В окне удаления обязательно показывай, что именно удаляется, название объекта и предупреждение о связанных данных, если сервер может запретить удаление. Кнопка удаления должна называться `Удалить`, желательно с красным фоном `#FF742C27`.
- Все новые русские тексты в XAML и `.cs` сохраняй в UTF-8 без mojibake. Символы закрытия должны быть нормальными: `×` или `✕`, а не `?` и не битые символы из неверной кодировки.
